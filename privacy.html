카드매치 개인정보처리방침

시행일: 2026-07-15 · 버전 1.3 (2026-09-03 개정: 실적 진행률·최근 검색어·사진으로 혜택 등록 항목 추가, 위치정보 사용 범위 명확화)

요약: 카드매치는 회원가입이 없고, 서버로 개인정보를 전송하지 않습니다. 등록한 카드 목록은 사용자 기기 안에만 저장됩니다. 카드번호·거래내역은 수집하지 않으며, 위치정보는 "내 주변 혜택" 조회 시에만 일시적으로 사용하고 저장하지 않습니다.

1. 수집하는 정보

  • 사용자가 직접 등록한 보유 카드 상품명 목록 — 기기 내 저장소(localStorage)에만 저장되며, 외부로 전송되지 않습니다. 카드번호·유효기간·CVC 등 결제정보는 입력받지 않습니다.
  • 실적 진행률용 이번달 사용액 — "실적 진행률" 기능에서 사용자가 직접 입력한 숫자입니다. 은행·카드사 거래내역을 조회·연동하지 않으며, 기기 내 저장소에만 보관되고 매월 자동으로 초기화됩니다.
  • 최근 검색어 — 재검색 편의를 위해 최근 5개까지 기기 내 저장소에만 보관됩니다.
  • 사진으로 등록한 혜택 정보 — "사진으로 혜택 등록" 기능 사용 시, 사용자가 선택한 사진 속 글자를 기기 안에서만 인식(온디바이스 OCR)해 카테고리·혜택 내용·조건을 추출합니다. 사진 원본과 인식 결과는 외부 서버로 전송되지 않고 기기 내 저장소에만 저장되며, 사용자가 직접 확인·수정한 뒤에만 저장됩니다. 글자인식 엔진 파일(범용 프로그램 파일이며 사용자 데이터를 담고 있지 않음) 자체는 최초 1회 인터넷에서 내려받습니다. 이렇게 등록한 혜택은 카드사 공식자료로 검증된 정보가 아니며, 다른 사용자와 공유되지 않습니다.
  • 위치정보 — "내 주변 혜택" 기능 사용 시에만, 근처 매장을 찾기 위해 카카오 위치검색 API 호출에 일시적으로 사용됩니다. 개발자의 서버는 존재하지 않으며 위치정보를 수신·저장하지 않습니다(기기에서 카카오 서버로 직접 조회). 이 기능을 사용하지 않으면 위치정보는 전혀 접근되지 않습니다.
  • 광고 식별자(ADID) — 앱 내 광고(Google AdMob) 게재 시 Google이 광고 제공 목적으로 처리할 수 있습니다. 자세한 내용은 Google 개인정보처리방침을 참조하세요.

2. 수집하지 않는 정보

  • 이름, 연락처, 이메일 등 개인 식별 정보 (회원가입 없음)
  • 카드번호 등 결제수단 정보
  • 카드 거래내역·이용실적
  • 위치정보의 저장·기록 (일시적 조회에만 사용하고 어디에도 남기지 않음 — 위 1항 참조)

3. 정보의 보관 및 삭제

등록된 카드 목록은 사용자 기기에만 보관되며, 앱 삭제 또는 앱 데이터 삭제 시 즉시 완전히 삭제됩니다. 개발자는 해당 정보에 접근할 수 없습니다.

4. 제3자 제공 및 광고

본 앱은 Google AdMob 광고를 게재할 수 있으며, 이 과정에서 Google이 광고 식별자 등 정보를 자체 정책에 따라 처리할 수 있습니다. 개발자는 이 외의 어떠한 개인정보도 제3자에게 제공하지 않습니다.

5. 콘텐츠의 성격 고지

본 앱이 제공하는 카드 혜택 정보는 카드사 공시 및 공개 자료를 바탕으로 한 참고용 정보이며, 금융상품 판매·중개·자문에 해당하지 않습니다. 정확한 혜택 조건은 각 카드사의 약관 및 상품설명서를 따릅니다.
